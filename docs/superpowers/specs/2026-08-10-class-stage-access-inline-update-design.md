# 학급 THINK 단계 접근 상태 인라인 갱신 설계

## 목표

교사용 수업 운영에서 단계별 `비공개`·`읽기 전용`·`작성 가능`을 변경했을 때, 저장 성공 후 수업 상세 화면 전체를 다시 불러오지 않고 선택한 단계의 UI만 즉시 반영한다.

## 범위

- 학급별 `class_lesson_stage_access` 설정 화면만 변경한다.
- 기존 Edge Function 요청과 권한 검증, 데이터 저장 방식은 유지한다.
- 저장 성공 시 선택된 행의 세 버튼 활성 상태와 접힌 헤더의 해당 단계 배지를 갱신한다.
- 저장 실패 시 서버 저장 전 화면 상태를 유지하고 오류를 알린다.

## 설계

`TeacherAdminModule.setClassStageAccess`는 현재 성공 후 `openClassDetailSubView(classId)`를 호출한다. 이 호출을 제거하고, 요청 성공 뒤 DOM에서 같은 `lessonId`·`stageCode`를 갖는 버튼 그룹의 활성 클래스를 조정한다. 해당 차시의 축약 배지에도 안정적인 식별자를 부여해 색상·아이콘·텍스트를 변경한다.

요청이 진행되는 동안에는 클릭한 버튼 그룹을 비활성화해 중복 저장을 막고, 완료 시 다시 활성화한다. 실패하면 UI 변경을 하지 않으므로 기존 상태가 그대로 남는다. 현재 펼쳐진 상세 설정과 스크롤 위치는 DOM을 교체하지 않으므로 보존된다.

## 오류 처리

- Edge Function 실패: 기존 alert를 유지하고 버튼 그룹을 다시 활성화한다.
- 필수 DOM 요소가 없는 경우: 저장은 성공으로 처리하고, 존재하는 요소만 갱신한다.

## 테스트

정적 모듈 테스트로 전체 상세 화면 재호출이 제거됐는지, 단계별 버튼·배지 식별자와 인라인 갱신 코드가 있는지 확인한다. 기존 수업 운영 및 학생 접근 상태 테스트도 함께 실행한다.
