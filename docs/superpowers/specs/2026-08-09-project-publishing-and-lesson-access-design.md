# 프로젝트 게시 및 차시 학생 활동 상태 설계

## 상태

- 프로젝트 `is_published`: 기본 `false`. 게시된 프로젝트만 담당 학급 학생에게 보인다.
- 차시 `student_access_mode`: 기본 `read_only`. 값은 `hidden`, `read_only`, `writable`이다.
- `hidden`은 학생에게 차시를 숨기고, `read_only`는 열람만, `writable`은 작성·수정을 허용한다.

## 적용 범위

- 프로젝트 카드에 학생 게시 토글을 둔다.
- 차시 카드에 `학생 활동: 비공개 / 읽기 전용 / 작성 가능` 선택기를 둔다.
- 게시 프로젝트는 담당 교사의 모든 학급에 자동 반영되며, 새로 만든 학급도 별도 연결 없이 반영된다.
- 학생 목록은 게시 프로젝트와 숨김이 아닌 차시만 프로젝트·차시 순서대로 보인다.
- 학생의 작성 API는 `writable` 상태인 차시만 허용한다.

## 기존 흐름

- 기존 프로젝트 수동 학급 연결과 수업 열기 흐름은 호환성을 위해 유지하되, 학생 공개·작성 권한의 판단 기준으로 사용하지 않는다.
- 기존 프로젝트는 비공개, 기존 차시는 읽기 전용으로 초기화한다.
