# 개인 수업 설계 전환 설계

## 목적

수업 설계 프로젝트를 작성 교사 개인의 자료로 한정한다. `초안`과 `공개` 상태를 없애고, 다른 교사가 프로젝트를 조회하거나 자신의 학급에 연결하는 기능을 제거한다.

## 사용자 경험

- 수업 설계 목록과 상세 화면에서 초안·공개 상태 배지, 공개하기 버튼, 공개 중·학급 연결 가능 안내를 제거한다.
- 교사는 자신이 작성한 프로젝트만 수업 설계 목록과 학급의 프로젝트 선택 목록에서 본다.
- 프로젝트를 저장한 뒤에는 별도의 공개 절차 없이, 작성자가 자신의 학급에 연결하고 차시를 열어 학생 수업을 진행한다.
- 학생 수업을 시작하는 조건은 기존처럼 교사가 해당 프로젝트를 자신의 학급에 연결하고 차시를 여는 것이다.

## 데이터와 권한

- 프로젝트의 기존 `visibility` 컬럼은 호환성을 위해 유지하되, 새 프로젝트와 기존 프로젝트 모두 `private` 값으로 둔다.
- 마이그레이션은 기존 `published` 프로젝트를 `private`으로 일괄 변경하고, 기본값을 `private`으로 유지한다.
- 프로젝트, 버전, 차시 조회 정책은 승인된 교사라도 작성자 본인의 자료만 읽도록 제한한다.
- Edge Function의 `list_projects`는 요청 교사의 `author_id`와 일치하는 프로젝트만 반환한다.
- Edge Function의 `attach` 작업은 연결하려는 프로젝트가 요청 교사의 소유인지 확인한다. 다른 교사의 프로젝트 ID를 알고 있어도 학급에 연결할 수 없다.
- `publish` 작업은 제거한다. 클라이언트도 이를 호출하지 않는다.

## 화면과 코드 범위

- `teacherAdmin.js`: 공개 상태 UI와 공개 호출을 제거하고, 프로젝트 카드·상세 헤더를 개인 프로젝트 흐름으로 단순화한다.
- `supabase-client.js`: 공개 API 래퍼를 제거한다.
- `manage-class-projects` Edge Function: 공개 처리 분기를 제거하고, 프로젝트 목록·학급 연결의 소유권 검사를 적용한다.
- 새 Supabase 마이그레이션: 기존 공개 데이터를 비공개로 되돌리고, 프로젝트/버전/차시 읽기 정책을 소유자 전용으로 교체한다.

## 오류 처리

- 타인 소유 프로젝트 연결 요청은 권한 오류로 거부한다.
- 프로젝트 목록은 더 이상 타인 자료를 반환하지 않으므로, 선택 화면에는 소유 프로젝트만 표시된다.

## 검증

- 정적 회귀 테스트로 공개 상태 UI·클라이언트 호출·공개 목록 조건이 제거되었는지 확인한다.
- Edge Function 코드 테스트로 목록이 소유자 기준이고, 연결 시 소유권 확인이 있는지 확인한다.
- JavaScript 문법 검사와 전체 테스트를 실행한다.
