# 교사용·마스터 교사용 대시보드 권한 및 메뉴 설계

## 목적

마스터 교사는 일반 교사와 같은 수업 운영 경험을 유지하면서, 공용 학생 계정 관리와 교사 가입 승인 업무를 수행한다. 마스터 권한은 다른 교사의 수업·학생 활동·평가 데이터를 열람하거나 수정하는 권한을 포함하지 않는다.

## 메뉴 구조

모든 승인된 교사는 로그인 직후 `내 수업 > 수업 현황`으로 진입한다.

```text
교사용 대시보드
├─ 내 수업
│  ├─ 수업 현황
│  ├─ 수업 만들기
│  └─ 내 수업의 학생 활동·평가
│
└─ 계정 관리
   └─ 학생 관리
      ├─ 전체 학생 목록
      ├─ 학생 계정 일괄 생성
      └─ 비밀번호 초기화
```

마스터 교사에게만 `계정 관리` 아래에 다음 메뉴를 추가한다.

```text
계정 관리
└─ 교사 관리
   ├─ 승인 대기 교사
   └─ 승인된 교사
```

## 역할과 권한

| 기능 | 일반 교사 | 마스터 교사 |
| --- | --- | --- |
| 자신의 수업 생성·운영·평가 | 가능 | 가능 |
| 다른 교사의 수업·활동·평가 열람 또는 수정 | 불가 | 불가 |
| 전체 학생 계정 목록 조회 | 가능 | 가능 |
| 학생 계정 일괄 생성 | 가능 | 가능 |
| 학생 비밀번호 초기화 | 가능 | 가능 |
| 교사 가입 요청 승인·거절 | 불가 | 가능 |

학생 계정은 담당 교사에 따라 분리하지 않는다. 모든 승인된 교사가 하나의 전체 학생 계정 목록을 공동으로 관리한다.

## 학생 관리

학생 관리 화면에는 학번, 이름, 생성일, 비밀번호 초기화 작업을 표시한다.

- 일괄 생성 시 학년, 반, 학생 수, 초기 비밀번호 규칙을 입력한다.
- 이미 존재하는 학번은 생성하지 않고 중복 사유를 결과에 표시한다.
- 비밀번호 초기화 전에는 대상 학생과 새 비밀번호를 다시 확인한다.
- 학생 계정 활성·차단, 담당 교사 배정·해제, 수업·평가 데이터 열람은 이 기능 범위에서 제외한다.

## 교사 관리

교사 관리 화면은 이름, 이메일, 가입 요청일 또는 승인일을 표시한다.

- 신규 교사는 가입 후 `승인 대기` 상태가 된다.
- 마스터는 대기 교사를 승인 또는 거절할 수 있다.
- 승인된 교사는 일반 교사용 대시보드와 공용 학생 관리 기능을 이용한다.
- 거절된 교사는 교사용 기능에 접근할 수 없다.
- 교사 차단, 교사 기본 정보 편집, 교사의 수업·평가 데이터 열람은 범위에서 제외한다.

## 데이터 접근 규칙

수업, 학생 활동 기록, 평가 데이터는 생성 교사 ID와 연결한다.

- 교사는 자신의 ID로 생성된 수업과 해당 수업의 활동·평가만 조회하고 수정할 수 있다.
- 마스터도 다른 교사가 생성한 수업·활동·평가에는 접근할 수 없다.
- 학생 계정 목록 및 생성·비밀번호 초기화는 승인된 교사 전체에 공통으로 허용한다.
- 교사 가입 상태의 조회·승인·거절은 마스터에게만 허용한다.
- 화면의 메뉴 노출과 별개로 데이터 요청 단계에서도 위 권한을 강제한다.

## 화면 동작과 예외 처리

- 승인 대기 교사는 로그인 시 승인 대기 안내만 확인한다.
- 거절된 교사는 로그인 시 거절 안내만 확인한다.
- 일반 교사가 교사 관리 화면이나 관련 요청을 직접 호출해도 접근을 거부한다.
- 다른 교사의 수업·활동·평가 데이터는 목록에 표시하지 않으며, 직접 요청도 거부한다.

## 검증 기준

다음 네 유형의 계정으로 메뉴 노출과 데이터 접근을 검증한다.

1. 일반 교사: 내 수업과 학생 관리만 이용 가능하며, 교사 관리는 이용 불가하다.
2. 마스터 교사: 내 수업, 학생 관리, 교사 관리 이용 가능하며, 타 교사 수업 데이터는 이용 불가하다.
3. 승인 대기 교사: 승인 대기 안내만 확인 가능하다.
4. 거절된 교사: 거절 안내만 확인 가능하다.

또한 학생 계정 일괄 생성의 중복 학번 처리와 학생 비밀번호 초기화를 확인한다.
