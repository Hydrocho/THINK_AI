# 학생 명단 붙여넣기 등록 설계

## 목적

교사가 엑셀에서 복사한 학생 명단을 붙여넣어 학생 계정을 한 번에 생성한다. 기존의 학년·반·인원 입력과 학생별 이름 입력 방식은 이 흐름으로 대체한다.

## 입력 형식

붙여넣기 영역에는 아래 예시를 placeholder로 표시한다.

```text
3    2    1    김하늘
3    2    2    이준호
3    2    3    박서연
```

각 행은 `학년`, `반`, `번호`, `이름` 순서다. 탭, 쉼표, 또는 연속 공백을 열 구분자로 허용한다. 제목 행에 대한 별도 안내 문구는 표시하지 않는다.

## 처리 흐름

1. 교사가 명단을 붙여넣는다.
2. 브라우저가 각 행을 파싱하고 형식을 확인한다.
3. 미리보기에서 학번, 이름, 등록 가능 여부를 표시한다.
4. 형식 오류 행과 기존 학번 중복 행은 오류 사유를 표시하고 생성 대상에서 제외한다.
5. 교사가 `N명 계정 생성`을 눌러 정상 행만 실제로 생성한다.

## 검증 규칙

- 학년은 1자리 정수, 반과 번호는 1~2자리 정수여야 한다.
- 이름은 공백 제거 후 비어 있으면 안 된다.
- 같은 붙여넣기 안에서 중복된 학번은 모두 오류로 표시한다.
- 서버에서 이미 존재하는 학번도 미리보기 단계 또는 생성 결과에서 중복으로 표시한다.
- 실제 계정 생성은 미리보기 확인 후에만 수행한다.

## 범위 제외

- CSV/XLSX 파일 직접 업로드
- 제목 행 자동 인식 안내
- 학생 계정 활성·차단
- 담당 교사 배정
