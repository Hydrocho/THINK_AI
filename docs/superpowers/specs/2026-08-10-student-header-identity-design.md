# 학생 헤더 식별 정보 표시 설계

## 목표

학생 로그인 후 상단 오른쪽 영역에 역할, 학번, 이름을 차례로 표시한다.

## 범위

- 학생 역할 태그 다음에 학번을 `30101`처럼 접미사 없이 표시한다.
- 학번 오른쪽에 학생 이름을 표시한다.
- 기존 로그인·세션 복원·비밀번호 변경 완료 흐름에서 같은 규칙을 사용한다.
- 학생 이름을 조회하지 못한 경우에도 학번은 표시한다.

## 설계

`AuthModule.prepareStudent`이 학생 헤더를 구성하는 단일 지점으로 유지한다. 현재 학생 이름이 있으면 이름만 표시하는 분기를 없애고, 학번과 이름을 각각 헤더 요소에 채운다. 공통 헤더에는 학번 전용 요소를 추가하며, 학생이 아닌 역할에서는 이 요소를 숨겨 기존 교사·관리자 표시를 보존한다.

## 데이터 흐름

학생 로그인 및 세션 복원은 `student_number`와 `student_name`을 `prepareStudent`에 전달한다. 이 함수는 학번을 새 전용 요소에, 이름을 기존 `lblUserName`에 넣는다. 학생 로비에서 늦게 받은 이름은 기존 이름 요소만 갱신하므로 학번 표시에는 영향을 주지 않는다.

## 검증

정적 회귀 테스트로 공통 헤더에 학번 요소가 존재하는지, 학생 준비 함수가 `번` 접미사 없이 학번과 이름을 독립적으로 표시하는지 확인한다. 기존 전체 Node 테스트도 실행한다.
