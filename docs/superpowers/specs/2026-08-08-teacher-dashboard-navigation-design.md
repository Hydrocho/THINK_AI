# 교사용 대시보드 탐색 구조 설계

## 목적

교사용 화면을 계정 관리 중심에서 수업 운영 중심으로 바꾸고, 넓은 화면을 활용할 수 있는 전체 폭 레이아웃을 제공한다.

## 레이아웃

- 교사 대시보드는 브라우저 좌우 여백과 최대 폭 제한 없이 전체 폭을 사용한다.
- 왼쪽 사이드바는 처음에 열린 상태(약 215px)로 표시한다.
- 상단 왼쪽 메뉴 버튼은 사이드바를 열린 상태와 아이콘 전용 상태(약 64px) 사이에서 전환한다.
- 아이콘 전용 상태에서도 수업 현황, 새 활동 생성, 학생 관리, 마스터 전용 교사 관리에 접근할 수 있다.

## 메뉴 구조

```text
내 수업
  수업 현황
  + 새 활동 생성

계정 관리
  학생 관리
  교사 관리 (마스터 교사만)
```

기존의 독립된 `빠른 작업` 영역은 제거한다. 새 활동 생성은 수업 관련 메뉴로 배치한다.

## 상단 경로

교사 대시보드 콘텐츠 상단에는 메뉴 버튼과 현재 위치 경로를 표시한다.

- 수업 현황: `내 수업 > 수업 현황`
- 학생 관리: `계정 관리 > 학생 관리`
- 교사 관리: `계정 관리 > 교사 관리`

메뉴 전환 시 제목, 설명, 활성 메뉴 표시, 상단 경로가 함께 갱신된다.

## 권한 및 기존 기능

- 교사 관리 메뉴는 승인된 마스터 교사에게만 표시한다.
- 학생 관리와 수업 현황의 기존 데이터·권한 동작은 바꾸지 않는다.
- 새 활동 생성은 기존 활동 생성 모달을 그대로 사용한다.

## 검증

- 교사 대시보드가 넓은 화면에서 전체 폭을 쓰는지 확인한다.
- 메뉴 버튼이 열린 메뉴와 아이콘 메뉴를 전환하는지 확인한다.
- 각 메뉴 선택 시 해당 패널과 경로가 일치하는지 확인한다.
- 일반 교사에게 교사 관리 메뉴가 보이지 않는지 확인한다.
