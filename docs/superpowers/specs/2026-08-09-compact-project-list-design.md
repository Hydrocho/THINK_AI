# 컴팩트 프로젝트 목록 및 순서 변경 설계

## 목적

수업 설계의 프로젝트 목록을 전체 너비 단일 열 카드로 바꾸고, 프로젝트별 차시 제목을 빠르게 확인할 수 있게 한다. 교사는 카드를 드래그해 프로젝트 순서를 바꾸며, 새 프로젝트는 항상 맨 위에 추가된다.

## 카드 구성

- 카드 전체는 수업 설계 영역의 가로 너비를 사용하고, 한 줄에 하나만 표시한다.
- 첫 줄에는 드래그 핸들, 프로젝트명, 총 차시 수, 수정일, 삭제 버튼을 둔다.
- 둘째 줄에는 `1차시 제목`, `2차시 제목`, `3차시 제목`을 차시 순서대로 표시한다.
- 4개 이상인 경우 세 번째 제목 뒤에 `+ n개 차시`를 표시한다.
- 기존 프로젝트 설명은 카드 목록에서 표시하지 않아 높이를 줄인다.
- 화면 폭이 좁으면 메타 정보와 차시 제목이 자연스럽게 줄바꿈된다.

## 순서 저장

- `projects` 테이블에 `project_order` 정수 컬럼을 추가한다.
- 기존 프로젝트에는 작성자별 현재 정렬 순서에 따라 1부터 순서를 초기 설정한다.
- 목록은 작성자별 `project_order` 오름차순으로 불러온다.
- 새 프로젝트는 해당 교사의 기존 최소 순서보다 작은 값으로 생성해 맨 위에 나타낸다.
- 드래그 후 놓으면 표시 순서대로 `project_order`를 재번호 부여하고 Edge Function으로 저장한다.
- 순서 변경은 저장 버튼 없이 즉시 반영한다.

## 권한과 오류 처리

- 순서 변경 요청은 Edge Function에서 각 프로젝트가 요청 교사의 소유인지 확인한다.
- 타인 소유 프로젝트 ID가 포함되거나 순서 데이터가 비정상이면 전체 요청을 거부한다.
- 기존 개인 전용 프로젝트·학급 연결 권한 규칙은 유지한다.

## 변경 범위와 검증

- `teacherAdmin.js`: 컴팩트 카드 렌더링, 프로젝트 드래그 앤 드롭, 순서 저장 호출을 추가한다.
- `main.css`: 프로젝트 목록의 단일 열·컴팩트·반응형 스타일을 추가한다.
- `supabase-client.js`, `manage-class-projects` Edge Function: 프로젝트 순서 저장 API를 추가한다.
- Supabase 마이그레이션: `project_order` 초기화와 조회·생성 흐름을 지원한다.
- 회귀 테스트로 카드의 차시 제목 요약, 단일 열 스타일, 새 프로젝트 최상단 생성, 소유권 검증을 확인한다.
