# 학급 기반 프로젝트 수업 운영 설계

## 메뉴

```text
수업 운영: 공용 학급 카드에서 프로젝트 선택, 활성화, 차시 열기, 진행 현황 확인
수업 설계: 내 프로젝트의 기본 정보, 차시별 활동 계획, 공개, 새 버전 생성
계정 관리: 학생 관리와 마스터 전용 교사 관리
```

기존 `새 활동 생성` 메뉴는 제거한다.

## 데이터 단위

- 학급은 학년·반으로만 구성되는 공용 카드다.
- 프로젝트는 작성자 소유의 개인 초안이며 여러 차시 계획을 가진다.
- 프로젝트 공개 시 모든 승인 교사가 볼 수 있다.
- 다른 교사는 공개 프로젝트를 복사해 자신의 프로젝트로 편집한다. 원본은 작성자만 편집한다.
- 프로젝트 수정은 새 버전을 생성한다.
- 학급 프로젝트 연결은 특정 프로젝트 버전의 사본을 보관한다. 원본의 이후 수정은 연결된 학급에 자동 반영되지 않는다.

## 학급 수업 운영

- 하나의 학급에 여러 프로젝트를 연결할 수 있다.
- 교사는 그중 하나를 현재 수업 프로젝트로 활성화 또는 비활성화한다.
- 프로젝트 활성화만으로 수업은 열리지 않는다.
- 교사가 해당 프로젝트의 차시 하나를 골라 `수업 열기`를 해야 학생이 접속할 수 있다.
- 열린 차시는 닫거나 다른 차시로 교체할 수 있다.
- 학급별 진행 및 학생 결과는 담당 교사별 수업 실행 기록으로 분리한다.

## 초기 화면

### 수업 운영

학급 카드마다 학년·반, 활성 프로젝트, 현재 열린 차시, `프로젝트 불러오기`, `차시 선택`, `수업 열기/닫기`, `진행 현황`을 표시한다. 연결된 프로젝트가 없으면 프로젝트 불러오기 버튼만 강조한다.

### 수업 설계

프로젝트 목록은 내 초안과 공개 프로젝트를 구분한다. 프로젝트 편집 화면은 기본 정보와 순서가 있는 차시 목록을 제공한다. 각 차시는 차시명, 핵심 질문, 학생 안내, THINK 단계, AI 질문 한도, 프로젝트 공통 평가 기준을 사용한다.

## 권한

- 승인된 모든 교사는 공용 학급을 보고 공개 프로젝트를 복사할 수 있다.
- 프로젝트 원본·새 버전·공개 설정은 작성자만 변경한다.
- 마스터 권한은 프로젝트 편집 권한을 추가로 갖지 않는다.
