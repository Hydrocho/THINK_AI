# 핵심 질문과 배경 설명 분리

승인된 설계: 교사는 필수 핵심 질문과 선택 배경 설명을 따로 작성한다. 학생은 핵심 질문을 항상 보고 배경 설명은 버튼으로 모달을 연다. 기존 질문을 자동 분리하지 않는다. AI에는 두 내용을 전달한다.

1. DB: `lesson_plans.background_description` 기본값 빈 문자열 추가. 기존 6인자 수정 RPC는 보존하고, 같은 소유권 검사를 사용하는 7인자 RPC 추가. PGlite로 기존 자료 보존, 저장·삭제·권한 검증.
2. 교사: 차시 생성·수정 입력란, 복제 기반 추가·삭제·정렬 경로, 클라이언트 직렬화와 서버 저장에 배경 필드 전달.
3. 학생: 조회 API 필드, 모든 단계에서 접근 가능한 배경 모달 버튼, 작은 제목. AI 서버는 인증된 차시의 배경을 DB에서 조회해 전달.
4. 검증: UI 복원·차시 전환·모달 안전 표시와 DB 테스트, 기존 회귀 검사. 운영 스키마 확인 후 해당 마이그레이션만 적용하고 변경 함수 배포. 토큰은 Windows 사용자 환경변수에서만 읽고 출력하지 않는다.
